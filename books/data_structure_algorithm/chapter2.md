## 2.1 配列

配列とは，同じ方の複数のデータを順番に並べたデータ構造のことで，配列には名前がつけられている．先頭から何番目にあるのかを**添字(そえじ)** で表し，各データを **「配列の要素」** と呼ぶ．一般に， **_添字は 0 から始まる_** ．

- 配列では同じ型のものしか扱えない．
- 配列の長さは変えられない．

以下の図は 1 次元配列の列で，A が配列名，n が配列のサイズ，上部の数字が添え字を表している．

この配列の場合，先頭から 2 番目の黄色の要素は`A[1]`として参照される．

!alt[画像挿入予定]()
_1 次元配列_

配列は，複数次元に拡張することも可能であるが，通常は 2 次元配列までで十分なことが多い．以下の図は 2 次元配列の例で，各要素を 2 個の添え字を用いて参照する．

この配列の場合，黄色の要素は`A[1][2]`として参照される．

!alt[画像挿入予定]()
_2 次元配列_

配列の大きな特徴の一つは，任意の要素の参照やデータの格納が，配列サイズに依存せず，$O(1)$の計算量で行える点である．

```
例：A[1]=9;
```

ただし，配列は，要素が連続的に配置されているため，途中にデータを割り込ませる場合は，それ以降のデータを 1 個ずつ後ろに移動させなければならず，その処理の計算量は $O(n)$になる．

### 配列の宣言と初期化

配列を使用するためには，宣言を行う必要があり，配列の宣言は「データ型」と「変数名」，要素数を記述する．

```:構文
配列のデータ型名 配列名[要素の数];
```

例えば，int 型(整数型)の要素を 5 個持つ配列は以下のように宣言する．

```c
int date1[5];
```

配列を使わない場合の宣言なら，`int date1, date2, date3, date4, date5`のようにコードが長くなってしまう，

配列も変数同様に，宣言しただけでは中身の値は不定値なため，必要に応じて初期化を行う．

配列の初期化には以下の 2 つの方法がある．

- **宣言と同時に初期化する方法**

```c:例
int date1[5]=[1,2,3,4,5]
```

- **値を 1 つずつ代入する方法**

```c:例
int date[5];
date1[0] = 1;
date1[1] = 2;
date1[2] = 3;
date1[3] = 4;
date1[4] = 5;
```

## 2.2 連結リスト

**連結リスト**は，配列と並ぶ最も基本的なデータ構造の 1 つであり，**セル**と呼ばれる「データ部」と「ポインタ部」で構成されたデータ構造を持つ．

単方向リンクリストとは連結リストの一種で，各セルが自分自身のデータと隣の要素のリンク(ポインタ)を持っており，先頭から最後尾までがリンクで繋がっている．

## 2.3 スタックとキュー

配列や連結リストは，要素を挿入する位置や取り出す位置に制約がないが，**要素を挿入する位置に制約がある**データ構造がスタック(stack)やキュー(queue)である．

**スタック**は，要素が入ってきた順に積み重ね，最後に入れた要素から順に取り出す **LFIO(Last In First Out：後入れ先出し)** の性質を持つ．スタックとは，「積み重ね」という意味である．

データを入れることを push(プッシュ)，データを取り出すことを pop(ポップ)と呼ぶ．書き込み・読み出しの位置は top というスタックポインタで表す．

!alt[画像挿入予定]()
_スタックの基本操作_

**キュー**は，要素を入ってきた順に一列に並べ，先に入れた要素から順に取り出すという**FIFO(First In First Out：先入れ後出し)** の性質を持つ．順番を待つ人の行列と同じ仕組みであるため「待ち行列」とも呼ばれる．要素を入れる作業をエンキュー(enqueue)，取り出す操作をデキュー(dequeue)と呼ぶ．

## 2.4 木構造

木構造はデータ間の階層的構造や，代償関係のような序列関係を表すのに適したデータ構造である．木のような形をしているので木構造と呼ばれる．

!alt[画像挿入予定]()
_木構造_

### 2.4.1 木構造の用語

木構造を構成する要素を「**ノード**」(node：節)と呼び，ノード間のつながりを「**エッジ**」(edge)という．

木構造には一つの**ルートノード**(root node：値)が存在し，それ以外のノードは親子関係を持つことで階層を形成する．

ルートノードに近い側が「**親ノード**」(parent node)で，遠い側が「**子ノード**」(child node)である．あるノードから見て，同じ親を持つノードを「**兄弟ノード**」(sibling node)と呼ぶ．

子のない末端のノードは「**葉ノード**」(leaf node：リーフノード)，「**終端ノード**」(terminal ndoe)，「**外部ノード**」(external node/outer node)という．

!alt[画像挿入予定]()
_木のレベル_

ルートノードを基準に，あるノードまでのエッジの数を「**深さ**」(depth/level)という．ルートノードの深さは 0 となる．

また，あるノードを基準に，その子孫の葉ノードのうち最も深いものまでのエッジ数を「**高さ**」(height)という．根ノードの深さは最も深い葉ノードの深さに等しく，これが木構造全体の高さとなる．
同じ深さにあるノードの数を「**幅**」(width)という．

木の中で特定のノードおよびその子孫を「**部分木**」(subtree：**サブツリー**)という．

### 2.4.2 2 分木

親ノードが持つ子ノードの数が$N$個以下に制限されているものを$N$分木と呼ぶ．

$N$分木の中で$N=2$の木を**2 分木**と呼び，2 分木では，ノードの左側に繋がる部分を左の子(**左部分木**)，右側につながる部分を右の子(**右部分木**)という．

また，2 分木の中で根から葉までの深さが全て同じものを「**完全 2 分木**」と呼ぶ．

### 2.4.3 木の走査法

木構造の各ノードが持っているデータを探して読み出すことを「**木の走査**」という．

2 分木の走査法には，大きく分けると**深さ優先探索**と**幅優先探索**がある．

#### 深さ優先探索

深さ優先探索は，左部分木を優先して階層が下のデータを先に読み出す方法である．

葉以外の節のデータと，葉のデータを読み出す順番の違いにより，**行きがけ順**(先行順)探索と**通りがけ順**(中間順)探索，**帰りがけ順**(後行順)探索の 3 種類がある．

**① 行きがけ順(先行順)探索**
行きがけ順探索は，節，左部分木，右部分木の順番で読み出す方法．

通りがけ順は，左部分木，節，右部分木の順番で読み出す方法．

!alt[画像挿入予定]()

**③ 帰りがけ(後行順)探索**
