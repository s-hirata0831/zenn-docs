## 2.1 配列

配列とは，同じ方の複数のデータを順番に並べたデータ構造のことで，配列には名前がつけられている．先頭から何番目にあるのかを**添字(そえじ)** で表し，各データを **「配列の要素」** と呼ぶ．一般に， **_添字は 0 から始まる_** ．

- 配列では同じ型のものしか扱えない．
- 配列の長さは変えられない．

以下の図は 1 次元配列の列で，A が配列名，n が配列のサイズ，上部の数字が添え字を表している．

この配列の場合，先頭から 2 番目の黄色の要素は`A[1]`として参照される．

!alt[画像挿入予定]()
_1 次元配列_

配列は，複数次元に拡張することも可能であるが，通常は 2 次元配列までで十分なことが多い．以下の図は 2 次元配列の例で，各要素を 2 個の添え字を用いて参照する．

この配列の場合，黄色の要素は`A[1][2]`として参照される．

!alt[画像挿入予定]()
_2 次元配列_

配列の大きな特徴の一つは，任意の要素の参照やデータの格納が，配列サイズに依存せず，$O(1)$の計算量で行える点である．

```
例：A[1]=9;
```

ただし，配列は，要素が連続的に配置されているため，途中にデータを割り込ませる場合は，それ以降のデータを 1 個ずつ後ろに移動させなければならず，その処理の計算量は $O(n)$になる．

### 配列の宣言と初期化

配列を使用するためには，宣言を行う必要があり，配列の宣言は「データ型」と「変数名」，要素数を記述する．

```:構文
配列のデータ型名 配列名[要素の数];
```

例えば，int 型(整数型)の要素を 5 個持つ配列は以下のように宣言する．

```c
int date1[5];
```

配列を使わない場合の宣言なら，`int date1, date2, date3, date4, date5`のようにコードが長くなってしまう，

配列も変数同様に，宣言しただけでは中身の値は不定値なため，必要に応じて初期化を行う．

配列の初期化には以下の 2 つの方法がある．

- **宣言と同時に初期化する方法**

```c:例
int date1[5]=[1,2,3,4,5]
```

- **値を 1 つずつ代入する方法**

```c:例
int date[5];
date1[0] = 1;
date1[1] = 2;
date1[2] = 3;
date1[3] = 4;
date1[4] = 5;
```

## 2.2 連結リスト

**連結リスト**は，配列と並ぶ最も基本的なデータ構造の 1 つであり，**セル**と呼ばれる「データ部」と「ポインタ部」で構成されたデータ構造を持つ．

!alt[画像挿入予定]()
_セルの構造_

ポインタを辿ることでデータを取り出すことができ，ポインタには次のデータのアドレスが格納されている．

単方向リンクリストとは連結リストの一種で，各セルが自分自身のデータと隣の要素のリンク(ポインタ)を持っており，先頭から最後尾までがリンクで繋がっている．

_線形リスト_

連結が 1 次的であるため**線形リスト**と呼ばれ，連結リストの末尾セルのポインタは空(NULL)である．

連結リストにおける要素の挿入や削除はリストの再生成の必要がなく，ポインタの付け替えだけで実行できるので，計算量は$O(1)$となる．

しかし，要素の探索や読み書きを行う場合，連結リストの先頭から順に辿る必要があるため，計算量は$O(n)$になる．

## 2.3 スタックとキュー

配列や連結リストは，要素を挿入する位置や取り出す位置に制約がないが，**要素を挿入する位置に制約がある**データ構造がスタック(stack)やキュー(queue)である．

**スタック**は，要素が入ってきた順に積み重ね，最後に入れた要素から順に取り出す **LFIO(Last In First Out：後入れ先出し)** の性質を持つ．スタックとは，「積み重ね」という意味である．

データを入れることを push(プッシュ)，データを取り出すことを pop(ポップ)と呼ぶ．書き込み・読み出しの位置は top というスタックポインタで表す．

**キュー**は，要素を入ってきた順に一列に並べ，先に入れた要素から順に取り出すという**FIFO(First In First Out：先入れ後出し)** の性質を持つ．順番を待つ人の行列と同じ仕組みであるため「待ち行列」とも呼ばれる．要素を入れる作業をエンキュー(enqueue)，取り出す操作をデキュー(dequeue)と呼ぶ．
